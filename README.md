
# Gestão de Estoque em Python

Sistema de gerenciamento de estoque desenvolvido em Python, com execução pelo terminal e armazenamento de dados em arquivo JSON.

## Funcionalidades

- Cadastro de produtos
- Consulta de produtos cadastrados
- Registro de entrada de produtos
- Registro de saída de produtos
- Identificação de produtos com estoque baixo
- Salvamento automático dos dados em arquivo JSON


## Tecnologias e conceitos aplicados

- **Python:** linguagem principal do projeto.
- **JSON:** armazenamento e persistência dos dados.
- **Git:** controle de versão do código.
- **GitHub:** hospedagem do repositório.
- **Manipulação de listas:** organização e gerenciamento dos produtos.
- **Funções:** modularização e organização do código.
- **Tratamento de exceções:** prevenção e tratamento de erros.
- **Manipulação de arquivos:** leitura e escrita de dados.


## Como executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/RobertJuan/gestao-de-estoque-python.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd gestao-de-estoque-python
   ```

3. Execute o programa:
   ```bash
   python estoque.py
   ```

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação, manipulação de listas, funções, tratamento de erros, persistência de dados com JSON e controle de versão com Git.
